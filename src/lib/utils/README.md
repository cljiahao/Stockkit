# src/lib/utils

General-purpose helpers: `cn` (class-name merge), shared form-field
classes (`FORM_LABEL_CLASS`/`FORM_ERROR_CLASS`), the codified "ledger"
hero-number type scale (`LEDGER_LG_CLASS`/`LEDGER_MD_CLASS`/`LEDGER_SM_CLASS`
— font-mono tabular-nums at three sizes, compose with `cn()` to layer a
status color on top), request-origin and logging utilities.
