skill from an approved spec in `../specs/` — one file per feature, named
`YYYY-MM-DD-<topic>.md`.

- `2026-07-22-landing-login-color-refresh.md` — the structural-parity plan.
- `2026-07-22-landing-visual-refresh.md` — the visual-polish follow-up plan.
- `2026-07-26-component-consumption-and-bundles.md` — a shared
  `product_components` + `record_linked_movement` mechanism reconciling the
  raw-material-linking and bundles specs.
- `2026-07-26-product-variant-grouping.md` — `parent_product_id`/
  `variant_label` SKU grouping (bundles excluded, see above).
- `2026-07-26-stock-take-cycle-count.md` — batch physical-count sessions.
- `2026-07-26-time-aware-low-stock-alerting.md` — vendor-declared seasonal
  alert suppression.
- `2026-07-26-customer-return-movement-reason.md` — adds a `'return'`
  stock-movement reason.
- `2026-07-26-inventory-valuation-export.md` — on-demand CSV valuation
  export.
